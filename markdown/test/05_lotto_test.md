# `Lotto`

## 당첨 번호 유효성

### 유효한 케이스

- 1 ~ 45 사이의 값
- 6개의 수

### 유효하지 않은 케이스

- 6개 이상의 수
- 6개 미만의 수
- 요소 내 소수 존재
- 요소 내 NaN 존재
- 요소 내 Infinity 존재
- 안전한 정수값 범위를 넘어서는 수
- 요소 내 중복 값 존재
- 요소 내 값이 1 ~ 45의 범위 밖의 수

## `checkBonusNumber()` 보너스 번호 유효성

### checkBonusNumber 유효한 케이스

- 당첨 번호 내의 요소와 보너스 번호가 중복되지 않은 경우
- 보너스 번호가 1 ~ 45 사이의 값인 경우

### checkBonusNumber 유효하지 않은 케이스

1. `isSafeInteger()`의 false
    - NaN, Infinity, 소수, 2^53 이상, -2^53 이하
2. 음수
3. 1 이상, 45 이하의 범위 밖의 수
4. 당첨 번호내 요소와 중복
